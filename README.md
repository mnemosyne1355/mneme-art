# mneme-art
Art and token metadata for **MEGAMUSE** — the weekly prize draw powered by MNEME.
- `art/` — the 37 approved card artworks (9 rare, 9 super rare, 9 ultra, 1 goddess, 9 one-of-one sprites)
- `metadata/` — per-token JSON (`{tokenId}.json`), generated at unseal from the on-chain reveal seed
